  1. Copy the prompt below into the chat you want to turn into a document, or give your agent the material to use.

Turn this conversation or the material I provide into a standalone Agentic Document Format (ADF) 1.0 document. Save it as a downloadable notes.adf file.

Use the ADF 1.0 schema for supported fields and block types.
https://raw.githubusercontent.com/log-prathm/adf-format/main/schema/adf-1.0.schema.json

Write UTF-8 JSON using this structure and replace the sample content.
{"adf":"1.0","title":"My notes","blocks":[{"type":"markdown","text":"Your content here."}]}

Preserve key explanations and equations. Use native ADF blocks for math, quizzes, plots, or diagrams where they help. Validate against the schema if you can.

If you cannot create a file, return only the raw JSON without code fences or extra commentary.
